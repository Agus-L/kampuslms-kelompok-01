# Tabel Titik Rawan IDOR

Tabel titik rawan IDOR (*Insecure Direct Object Reference*) berikut mencakup seluruh 23 rute yang diidentifikasi pada audit keamanan Minggu 5, dilengkapi dengan Policy atau Query yang menutupnya di Minggu 7 sesuai spesifikasi proyek.
